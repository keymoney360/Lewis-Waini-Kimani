# Lewis Waini Kimani — Portfolio Website

A responsive static portfolio for Lewis Waini Kimani, aspiring MCA for Rware Ward, Nyeri County.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/lewis-waini-kimani-poster.jpeg` — supplied poster image

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `lewis-waini-kimani`.
2. Extract this ZIP file on your computer.
3. Open the extracted folder and upload the files and `assets` folder to the repository root. Make sure `index.html` is at the top level, not inside another folder.
4. On GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes and refresh the Pages section to find the published URL.

The website intentionally contains **no contact details**. The listed development priorities are presented as proposed discussion areas, not as claims of completed work or guaranteed outcomes.
